- **要約**: 固定テンプレート攻撃ではなく適応的なブラックボックス攻撃で間接 prompt injection 防御を再評価するフレームワーク。既存防御の多くは最適化された攻撃に対して報告値より大幅に弱く、特にタスク指定が緩い(open-ended)タスクで脆弱と示す。名前の通り AgentDojo を攻撃側から拡張する位置づけ。
- **本プロジェクトとの関係**: Firewalls 論文と対をなす「ベンチが甘い」側の最新の証拠。本プロジェクトの防御主張を出すなら、テンプレート攻撃だけでなく適応攻撃での評価を要求される根拠になる(査読者が突く先回り)。
